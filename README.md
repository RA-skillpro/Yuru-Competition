# ゆるコンペ Webサイト

共通トップと各回の開催サイトをまとめた静的サイトです。

- `index.html` / `portal.css`：共通トップ（趣旨、各回の開催記録、次回の案内）
- `editions/01/`：第１回 ポンチ絵コンペティションの開催記録。画像・CSS・JSも含めて保存しています。
- ルートの `winners.html`、`ceremony.html`、`workshop/`：従来URLを維持するための第１回ページ。第１回のナビゲーションは `editions/01/` に接続しています。
- ルートの `style.css` / `script.js` / `assets/`：従来URLのページが使用する資材です。

## 次回を追加するとき

1. `editions/02/` に次回のサイトを作成します。各回の画像・CSS・JSはそのフォルダ内に配置します。
2. 各回のサイトから共通トップへのリンク（通常 `../../index.html`）を設置します。
3. 共通トップの「各回の開催記録」にカードを追加し、「次回について」とお知らせ欄を更新します。
4. 参加条件やテーマ、日程、申込リンクは各回のサイトで案内します。
5. 開催終了後は「開催終了」を表示し、申込・投稿の導線を開催記録への導線に変更します。

既存の GitHub Pages を更新する際は、このリポジトリ全体（`editions/` を含む）を公開対象へ反映してください。今回の編集では公開・pushはしていません。

## ローカル確認

このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。
